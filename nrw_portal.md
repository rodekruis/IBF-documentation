# NRW Portal

The NRW portal is provided both as parth of IFRC Go and as a standalone page.

The main development is done in the [IFRC Go repo](https://github.com/rodekruis/go-web-app). The standalone page is provided in the [IBF repo](https://github.com/rodekruis/IBF/tree/main/portal/nrw-standalone), which wraps the content from the IFRC Go repo.
